# 0003. Локальная среда на Docker Compose

- Статус: принято
- Дата: 2026-11-11

## Контекст
Разработка не должна затрагивать боевой сайт. Среда должна одинаково подниматься на любой машине и быть удобной для автоматизации (WP-CLI, агент, CI).

## Решение
`docker-compose.yml` с сервисами: `wordpress` (php8.3-apache), `db` (MariaDB 11.4), `wpcli` (профиль `tools`), `phpmyadmin`, `mailpit`. Ядро WordPress — в именованном томе, `wp-content` — примонтирован из репозитория. Секреты в `.env` (в git только `.env.example`). Вся исходящая почта в локальной среде перехватывается Mailpit (mu-plugin `local-mailpit`).

## Последствия
- (+) Среда поднимается одной командой, боевые данные изолированы.
- (+) Формы можно тестировать, не рассылая писем реальным людям.
- (−) Bind-mount на Windows медленнее нативного; при необходимости переносим проект в WSL2.
