# 0001. Оставить WordPress в качестве CMS

- Статус: принято
- Дата: 2026-11-11

## Контекст
Текущий сайт runtime-m.by работает на WordPress. Владелец привык к wp-admin и должен сам править тексты, цены и новости без разработчика. Рассматривались альтернативы: headless-CMS + статический генератор (Astro/Next.js), конструкторы (Tilda).

## Решение
Остаёмся на WordPress (последняя версия, PHP 8.3) со стандартной админкой и блочным редактором.

## Последствия
- (+) Перенос контента, пользователей и SEO-метаданных без потерь; знакомая админка.
- (+) Огромная экосистема, дешёвый хостинг, проще передать поддержку.
- (−) Нужно следить за обновлениями и безопасностью; скорость обеспечиваем темой без конструктора и кэшированием (см. ADR 0002).
