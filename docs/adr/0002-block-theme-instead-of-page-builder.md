# 0002. Собственная блочная тема вместо конструктора страниц

- Статус: принято
- Дата: 2026-11-11

## Контекст
Устаревшие сайты на WordPress часто собраны на тяжёлых конструкторах (Elementor, WPBakery) и наборах шаблонов. Это даёт лишние сотни килобайт CSS/JS, плохие Core Web Vitals и привязку к платному плагину.

## Решение
Пишем собственную блочную тему (Full Site Editing) `runtime-m`:
- дизайн-система в `theme.json` (палитра, типографика, отступы, ширины);
- шаблоны и части шаблонов (шапка, подвал) в HTML-разметке блоков;
- библиотека паттернов для типовых секций (герой, услуги, преимущества, отзывы, цены, FAQ, контакты, карта, CTA), из которых владелец собирает страницы сам.

## Последствия
- (+) Минимум CSS/JS, высокие показатели Lighthouse, нет платных зависимостей.
- (+) Владелец редактирует сайт в стандартном редакторе WordPress.
- (−) Контент старых страниц, собранных конструктором, переносится в блоки вручную/полуавтоматически.
